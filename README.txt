NoxVisuals 1.7.1 (Fabric, Minecraft 1.21.4)

Как получить .jar для папки mods:
1. Установи JDK 21 и Gradle (или открой папку в IntelliJ IDEA как Gradle-проект).
2. В этой папке выполни:  gradle build
3. Готовый мод: build/libs/noxvisuals-1.7.1.jar
4. Закинь его в .minecraft/mods вместе с Fabric API для 1.21.4.

Клавиши: правый Shift - меню, G - граффити, левый Alt (зажать) - фрилок.

Сборка без ПК (с телефона):
1. Создай репозиторий на github.com и загрузи в него СОДЕРЖИМОЕ этой папки (включая .github).
2. Открой вкладку Actions: сборка запустится сама после загрузки.
3. Когда она станет зелёной, открой её и скачай артефакт noxvisuals-jar (внутри .jar).
B - колесо эмоций (зажми, наведи, отпусти)
